# Azure Retirement Motion

An [Opensquad](https://github.com/marcelodelima) multi-agent squad that runs the
**Azure service-retirement motion** end-to-end for a single customer engagement.
It pulls Azure service/feature retirement and end-of-support data, orchestrates a
customer PowerPoint deck, and produces both customer-facing and internal
artifacts — turning raw lifecycle data into a proactive, revenue-aware motion.

It can optionally consume a guarded candidate handoff from the separate
[Retirement Portfolio Opportunity Scorer](../retirement-portfolio-scorer/README.md),
but always revalidates the customer and current telemetry.

> **Framework only.** This repository contains the reusable squad framework
> (agents, pipeline, build scripts, reference data). It contains **no customer
> data**. Each run writes customer-scoped artifacts under `output/{run_id}/`,
> which is gitignored.

## What it produces

**Customer-facing**
- PowerPoint assessment deck (generated by the external Azure Service Retirements skill)
- Excel workbook — Read Me, retirement Summary, and one numbered, filterable resource sheet per retirement
- Consolidated execution / migration plan — one runbook section per retirement
- Proactive follow-up email

**Internal**
- Motion / opportunity plan with rough ACR bands and MSX framing
- One-page executive briefing
- Internal briefing PowerPoint deck (CSAM / v-team)
- Approval-bound MSX opportunity/milestone proposal and creation receipt
- Approval-bound internal account-team email with Top Revenue Motions snapshot
- Downloadable Outlook-ready `.eml` preview before account-team mail approval

## Pipeline

19 steps with human checkpoints at intake, customer confirmation, data review,
customer-deliverables approval, final deliverables approval, and a separate
hash-bound MSX creation approval plus a separate mail-send approval. See
[pipeline/pipeline.yaml](pipeline/pipeline.yaml).

## Prerequisites

- The external **Azure Service Retirements** skill cloned locally (set its path in
  [squad.yaml](squad.yaml) under `external_skills`). Requires `az login`,
  Node 18+, and `npm install`.
- Node.js for the build scripts under `_build/` (`exceljs`, `pptxgenjs`).

## Confidentiality

One run = one customer. Internal-only data (ACR, MSX opportunity framing) never
appears in customer-facing artifacts. See
[pipeline/data/customer-confidentiality-guard.md](pipeline/data/customer-confidentiality-guard.md).
